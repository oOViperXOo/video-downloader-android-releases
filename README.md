# Video Downloader Android updates

Public update metadata only. Application source is private.

No production APK is published here yet. There is no stable upgrade target.
The lite and full manifests deliberately report `available: false`; they do not offer downloads.
Production release publication is waiting for signing-certificate verification,
installed-version-code reconciliation and testing on an arm64 Android device.
Do not uninstall an existing app to test a replacement.

Lite and full share the package name com.eladwy.vdl. They are not interchangeable
upgrade targets. Future published metadata must match the variant and verified signing identity.
